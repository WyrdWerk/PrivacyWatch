# Baidu — Qianfan / API (research note, 2026-09-13)

Primary source: https://intl.cloud.baidu.com/en/doc/Agreements/s/bmesahnjh-intl-en

## Findings
- Training: AI Content that is not personal data may be used "to enhance the machine learning and AI technologies". Qianfan permits refusing processing for service optimization/troubleshooting/risk control via its feedback method, but this is not documented as a complete training opt-out.
- Retention: No API input/output retention period documented.
- ZDR: No ZDR or named no-training tier offered.
- Location: Processed "in countries where Qianfan Platform facilities" of affiliates/partners are located; cross-border transfers permitted.

## Notes
Qianfan user agreement (stated to prevail over general policies): inference inputs/outputs are customer data and "we will not conduct any unauthorized use and disclosure". See intl.cloud.baidu.com/en/doc/qianfan/s/Cmn5zc5tn.
