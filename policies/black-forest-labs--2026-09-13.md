# Black Forest Labs — API (FLUX) (research note, 2026-09-13)

Primary source: https://bfl.ai/legal/flux-api-service-terms

## Findings
- Training: FLUX API Service Terms: "Developer acknowledges that the foregoing means the Company may use Inputs and Outputs to train and improve its artificial intelligence models." No API opt-out; the website-ToS email opt-out is superseded for API use.
- Retention: No retention period documented for image API inputs/outputs (video outputs use a time-limited retrieval URL).
- ZDR: No public no-training/ZDR API tier; enterprise agreements may differ but are unpublished.
- Location: No storage region identified; EEA/UK/Swiss data "may be transferred to, and stored at/processed in countries outside" the collection country.

## Notes
API-specific terms control over the general ToS for API use and describe the training license as irrevocable. EU users are subject to separate EU API/developer terms. General ToS: bfl.ai/legal/terms-of-service.
