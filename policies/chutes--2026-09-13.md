## Chutes — research note (2026-09-13)

Pages read: https://chutes.ai/tos (ToS), https://chutes.ai/privacy (privacy policy), https://chutes.ai/dpa (linked DPA).

- TRAINING: off by default. ToS "No Training on Your Data": "We do not use your API requests, responses, or application content to train AI models."
- RETENTION: not stored. "We do not log, store, or persist the content of your API inference requests or responses." Only request metadata (timestamps, token counts, performance metrics) is collected. Content "exists only in memory for the duration of the request and is not stored."
- ZDR: yes, by design. Standard API mode is memory-only; E2E mode relays requests as an encrypted blob; TEE mode (confidential_compute) runs requests "inside hardware-isolated memory" with hardware-enforced privacy.
- LOCATION: decentralized. Independent third-party node operators (Bittensor ecosystem). TEE mode blocks access by Chutes or datacenter operators.
- OPT-OUT: not needed (no training). Website analytics apply to chutes.ai browsing only.
- INCIDENTS: none found. Status page (status.chutes.ai/incidents) lists operational incidents only; no confirmed data breach or regulatory action found.
- Confidence: high.
- Notes: first-party apps (chat.chutes.ai) store conversation history as a core feature, deletable by the user; third-party user-created chutes may have their own terms.
